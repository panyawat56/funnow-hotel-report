# FUNNOW Hotel Weekly Report

Work in progress: a demo built for the FUNNOW Group AI Management Trainee assignment.

Every Monday, the system is designed to read last week's hotel data from a Google Sheet, label each hotel with fixed rules, have an AI model draft a summary, check the draft, and email it.

The demo uses the mock data supplied with the assignment. It runs on the builder's own computer and sends test emails only to the builder.

This repository will hold the n8n workflow, setup notes and test results when they are ready.
